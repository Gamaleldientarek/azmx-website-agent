# Example site: working rules

- Publishing is the owner's. Never publish without an explicit yes.
- Back up the nodes you will change as JSON in `archive/backups/` before writing.
- Write on a branch, read it back, merge to main. Finished work lives on main.
- Keep template sections and assets. Never hide or remove a section without a yes.
- Arabic is the default language at `/`; English is at `/en`. Use «المنصة», not «البوابة».
